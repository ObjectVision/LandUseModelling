# Land Use Modelling

Configuration of the Land Use Scanner, student edition, built with [GeoDMS](https://github.com/ObjectVision/GeoDMS). The model is in `lus_demo/cfg` and its input in `lus_demo/data`. The documentation is on the [wiki](https://github.com/ObjectVision/LandUseModelling/wiki).
